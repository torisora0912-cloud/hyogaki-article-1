02最多カテゴリ「リスキリング無効論」——46件が語る構造

174件中最多の46件（26.4%）が「リスキリング無効論」に分類された。 「無効論」と名付けたが、リスキリングそのものを否定する声ではない。 構造的な問いだ——「スキルを得ても、採用する側が変わらなければ意味がない」。

ANALYSIS

柱１の設計は「スキルを上げれば就労機会が増える」という前提に立っている。しかし当事者が経験で積み上げてきた認識は逆だ——「スキルは既にある。採用する側の慣行が変わらないと意味がない」。この認識のずれが、55.7%という評価数字に表れている。

0337件が証言する「年齢差別」の現実

「年齢差別・採用現場の壁」カテゴリに37件が分類された。 法律で禁止されていない年齢を理由とした採用慣行が、 支援策の効果を根本から打ち消しているという指摘だ。

1982年 / 男性 / 正規雇用（正社員・公務員等）
「前回の公務員氷河期採用の方がまだ効果があった」という比較は鋭い。採用する側の意思決定に直接働きかける政策（公務員採用・企業への義務付け）の方が効果的だという提案として読める。

日本では採用時の年齢差別を明示的に禁じる法律が整備されていない。 「募集・採用における年齢制限禁止（努力義務）」はあるが、 違反への実効的な罰則がなく、企業の慣行を変える力は弱い。 当事者が求めているのは「努力義務」ではなく「実効ある法規制」だ。

ANALYSIS

「伴走支援の強化」は人員・予算の面では評価できる方向性だ。しかし伴走する先（求人票の質・選考後の待遇）が変わらなければ、「丁寧に低賃金求人に誘導する仕組み」になりかねないという懸念が当事者には根強い。

05「就労できた」その先——給与・処遇の問題14件

柱１の名称は「就労・処遇改善支援」だ。就労後の賃金・待遇も射程に入るはずだが、 当事者の声は「就労できた後の処遇改善の見通しが見えない」という方向に向かう。

介護や福祉など、低賃金で人手不足な業界を押し付けられそう。
1975年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
実際、ハローワークで氷河期世代に提示される求人に介護・清掃・警備が多いという声は複数の回答に共通して登場する。社会的に必要な職種だが、「就労支援」が低賃金業種への誘導になっていないか、という問いだ。
リスキリングしてもそもそもの給与体系が追いついてない。
1975年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）

第1回でも触れた「現役就労中・低賃金層への支援不足」の声は、 この給与・処遇の問題と表裏一体だ。 就労の有無だけでなく、就労の質（賃金・待遇・雇用形態）まで 射程に入れた支援設計が求められている。

「企業側への義務化・インセンティブ要求」カテゴリは8件と少ないが、 内容は具体的な政策提案になっている。 リスキリングより先に、採用する側を変えることを求める声だ。

ANALYSIS

いずれも「当事者のスキル・意欲の問題」ではなく「採用する側の構造を変える」アプローチだ。 リスキリング支援と企業への働きかけを同時に行わなければ、前者の効果は後者の壁に阻まれる—— これが174件の自由記述を通じて見えてきた最大の問いだ。

07効果があると感じる声も——条件付きの肯定

批判一色ではない。「こういう条件なら有効」という構成的な声も届いている。

自力で頑張れない（もしくは思考が狭くなってる）方には、リスキリング含め、提案して伴走してもらえるのは有効な人もいるかと思います。あとはメンタルケアをセットにしたうえで支援できる体制があれば。
1981年 / 女性 / 正規雇用（正社員・公務員等）
「メンタルケアをセットに」という条件は、この世代が長期にわたる消耗によって意欲・自己肯定感を削られてきた実態を踏まえた指摘だ。スキル支援だけでなく、心理的なサポートとの組み合わせが有効という提案として読める。
専門寄りのスキルと職種経験があり、企業側の社員に穴のある年齢層のカバーとして現状は仕事がある。身体が動くうちは自分ができて求められる仕事で役立ちたい。
1975年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
「穴のある年齢層のカバー」という表現が鋭い。氷河期世代の採用が薄かった企業では、その世代のスキルが組織の弱点になっている。これをマッチングに活かす逆転の発想も可能性として存在する。
