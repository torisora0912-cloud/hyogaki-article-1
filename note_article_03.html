今を生き延びれるかどうかの瀬戸際に高齢期の話をされても無意味。

1980年生まれ / 男性 / 無業（求職中）

Q15（柱３）に寄せられた一言だ。言葉は短いが、この世代の多くが抱える切迫感が凝縮されている。 「将来の備え」より「今の生存」——この優先順位のずれが、 柱２・柱３への評価を読み解く鍵になる。

147件の回答を分類すると、最多は「居場所づくり・社会参加支援の実効性への疑問（28件、19.0%）」だった。 「遅すぎる・今更感（20件）」がそれに続く。 注目すべきは「経済的支援・生活保障の優先を求める声（12件）」だ。 これは柱２への設計批判ではなく、「居場所より先に生活費をどうにかしてほしい」という 優先順位の問い直しだ。

02「本当に必要な人が来られるのか」——実効性への28件の疑問

柱２のコアである「居場所づくり・段階的支援」に対して、19.0%が実効性への疑問を訴えた。 批判の軸は3つだ。

① 支援が届かない問題——孤立しているからこそ来られない

本当に必要としている人が居場所にたどり着けると思えない。
1978年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
居場所を必要としている人ほど、情報収集や外出のハードルが高い。支援を「用意する」だけでは届かないという、実体験に基づく指摘だ。
居場所に関する周知がまだまだなのか、どのような居場所があるのか分からない。地域のコミュニティカフェやNPOの支援だと顔が知られてしまうので逆に居づらい。
1982年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
「顔が知られてしまう」という指摘はこの世代固有のプライバシー問題だ。地域密着型の支援が、逆に参加の壁になるケースがある。オンラインや匿名参加の選択肢が求められている。

② 成果の見えにくさ——前回も「効果があったか把握できていない」

前回もあったと思うが、成果があったかどうか把握できてない。就労支援はまだしも、居場所づくりはどの程度成果を期待できるのか？
1982年 / 男性 / 正規雇用（正社員・公務員等）
2019〜2022年のプログラムでも居場所づくりは実施された。その結果がどう評価・検証されたかが不明なまま、同様の施策が繰り返されることへの疑問だ。PDCAを可視化する必要がある。

③ 外に出ること自体がハードル

そもそも自発的に外に出るのか疑問。
1974年 / 女性 / 無業（求職中）
今更過ぎてメンタルボロボロ、人と関わるのが辛い。
1976年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
長年の消耗と対人関係での傷が、「居場所に行く」という最初の一歩を難しくしている。物理的な居場所の整備と並行して、精神的・心理的なアプローチが不可欠だ。

03「引きこもりイメージ」への反発——柱２設計への根本的な疑問

6件と少ないが内容が鋭いのが「引きこもり・能力不足イメージへの反発」だ。 柱２の設計そのものへの根本的な問いを含んでいる。

「社会参加に向けた段階的支援」という柱が、氷河期世代＝引きこもりや能力が無い人、というイメージを植え付ける悪質な印象操作だと思う。氷河期世代で長期無業になってしまう人がいるのは、職能があっても年齢バイアスや派遣社員など非正規雇用者への差別観によって雇用が阻まれているのであり、個人の能力不足の問題ではない。
1977年 / 女性 / 無業（求職中）
この一文は、柱２への批判の核心を衝いている。「社会参加ができていない」のは意欲や能力の問題ではなく、受け入れる側の構造の問題だ——という認識が、この世代に共通して根づいている。

柱２が「段階的に社会参加を促す」設計を取ることで、 「この世代は段階的なリハビリが必要な状態にある」という前提が暗示される。 しかし当事者の多くは、能力でも意欲でもなく、 構造的な排除によってその状態に置かれた——という認識を持っている。 設計の前提と当事者の自己認識のずれが、柱２への不信感の根底にある。

04「居場所より先に生活費を」——経済的支援の優先を求める12件

まず生きていける環境を整えて欲しい。税金や年金が支払えないのだから。
1971年 / 女性 / 無業（求職中）
そもそもこのご時世で金銭負担がかかる形でその場所への誘導は少ないおかねでやりくりするような人には荷が重いのでは？交通費負担ありならまだわかりますけど、就労できない状態の人。
1984年 / 女性 / 無業（求職していない）
居場所への参加に交通費・時間・心理的コストがかかる。経済的に余裕がない状態では、支援の場に出向くこと自体が困難だという指摘だ。
ANALYSIS

マズローの欲求階層に照らすと当然の話だが、生活の安定がない状態で「居場所づくり」「社会とのつながり」を提供しても、それを受け取る余力がない。まず経済的なセーフティネットを整えることが、柱２の効果を引き出す前提条件だ。

05「土木と介護しかない」——低賃金誘導批判7件

「中間的就労」「軽作業」として提示される仕事の質への批判が7件寄せられた。

近場の求人なんて土木と介護しかないのに？何が軽い作業だよ。何が地域清掃だよ。何が物品整理だよ。しかも土木と介護は要資格要経験でどこでその資格と経験得るんだよ。マジでふざけんな。
1975年 / 男性 / 無業（求職中）
中間的労働は超低賃金である事が予想され、親や生活保護などの補助がなければ成り立たなそう。
1979年 / 女性 / 正規雇用（正社員・公務員等）
「中間的就労」が名目上は「段階的な就労支援」であっても、実態として生活費を賄えない低賃金労働への誘導になるなら、それは支援ではなく消耗だという指摘だ。

「低家賃住宅・公営住宅への優先入居」が72.4%（160件）と突出して高い。 「生活保護申請への支援・簡素化」（60.2%）、「国民年金の追納・受給額補填」（46.6%）が続く。 上位3項目はいずれも「今すぐ生き延びるための生活基盤」に関わるものだ。 一方、「65歳以降の就労支援」は33.9%と最下位。 「高齢期支援」という柱名にもかかわらず、求められているのは老後の整備ではなく今の底支えだ。

Q15（自由記述）の146件を読むと、その数字が実感としての言葉に変わる。 「老後より今の生活をどうにかしてほしい」（14件、9.6%）という声が多く、 65歳以降を前提にした設計への違和感が続く。

07最多カテゴリ：「死ぬまで働けということか」——21件の反発

146件中最多の21件（14.4%）が「老後就労強制・生涯現役への反発」だった。 65歳以上の就労支援が「支援」ではなく「強制」として受け取られている。

現在50代で、そもそも65歳までまともに仕事をしているか想像出来ない。
1975年 / 女性 / 非正規雇用
生涯現役（死ぬまで生きるために働く）事にはなるんだろうな、と。仕方ないのかもですが。
1982年 / 男性 / 正規雇用
老後も一生働き続けないと安心して生活できないのかと思うと不安。働きたい場合はその選択肢を持てることは重要だと思うけど。年金の支給開始年齢を後ろ倒しにしないで欲しい。
1972年 / 女性 / 正規雇用（正社員・公務員等）
「働きたい人が働ける」選択肢は支持されている。問題は「働かざるを得ない」構造を前提にした設計だ。年金支給開始年齢の後ろ倒しへの不安と組み合わさり、「生涯現役」が強制に見える。
ANALYSIS

「65歳以降の就労支援」は、選択肢の拡充として設計されたはずだ。しかし年金制度への不信・受給額への不安と組み合わさると、「働かなければ生きられない」という強制として受け取られる。設計の意図と受け取られ方のギャップを埋める説明が必要だ。

08「老後より今」——現役優先を求める14件

今を生き延びれるかどうかの瀬戸際に高齢期の話をされても無意味。
1980年 / 男性 / 無業（求職中）
とりあえず今の生活をどうにかして欲しい。皆が高齢者になれる訳ではない。
1971年 / 女性 / 無業（求職中）
遺族年金、第三号被保険者の年金剥奪を狙っておいて何を言う？住まいの提供？現役世代にこそ必要なのにそこ放ったらかし？順番が違う。
1985年以降 / 女性 / 無業（求職していない）
「順番が違う」——この言葉が14件の声の共通点だ。老後の備えより現在の生活基盤を整えることが先決という優先順位の問い直しは、連載を通じて繰り返し登場するテーマだ。

09住宅・年金・生活保護——3つの生活基盤への声

住宅支援（17件）——「今すぐ必要」

住宅支援は今すぐ必要である。
1974年 / 女性 / 無業（求職中）
低家賃住宅・公営住宅への優先入居は、いますぐ行ってほしい。
1979年 / 女性 / 無業（求職中）

Q14では「低家賃住宅・公営住宅への優先入居」が160件（72.4%）と最多だった。 住宅支援は65歳以降ではなく「今すぐ」求められている。

年金（12件）——「年金だけでは生活できない」

年金だけでは、生活費がどう考えても足りなくなると思う。特に国民年金の人。
1975年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
現状、年金生活無理という状態で介護福祉？？？となります。年金生活となった時低額住宅になった時、生きていける生活のできるお金があるのか，まずそこが心配です。
1984年 / 女性 / 無業（求職していない）

生活保護（16件）——「申請しても受理されない」

生活保護を申請しても受理しない自治体があると聞く。手続きを簡素化しても受理されなければ意味がない。
1975年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
「申請の簡素化」はプログラムにも盛り込まれているが、実態として「水際対策」が続く現場では意味をなさないという指摘だ。制度設計と運用現場の乖離を是正する必要がある。

10「安楽死」という言葉が4件届いた

NOTE — この声をどう読むか

「安楽死させてほしい」「60歳で安楽死できるよう法整備を」という言葉が4件届いた。これを極端な意見として処理することはできない。30年にわたる構造的な放置が生んだ絶望の声として、政策立案者は正面から受け止める必要がある。

60歳で安楽死できるよう法整備にしてもらえれば、後の世代の負担をなるべく減らしてあげることができる。自己責任と言われ見捨てられ続けた世代だから最期も見捨ててくれて構わない。
1976年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
全部65歳から。絶望しかない。生活保護支援の要件が緩和されるのなら嬉しいが、口うるさい自称支援者に説教されるくらいなら安楽死の方が助かる。
1971年 / 女性 / 無業（求職していない）
「自己責任と言われ見捨てられ続けた」「全部65歳から。絶望しかない」——これらの言葉は、支援が届かない怒りと、30年間の放置への深い傷を映している。「安楽死」という言葉を選ばざるを得なかった文脈を、政策立案者は直視すべきだ。

この声は連載を通じて届いた最も重い言葉だ。 第4回（総括・Q17）ではさらに多くの同様の声が登場する。 私たちコミュニティとして、これらの声をどう提言に組み込むか—— 最終回に向けて、その言語化にも取り組んでいく。

11第3回のまとめ

柱２・柱３への293件の声が共通して示した構図はこうだ。

柱２：「段階的支援」の設計が「この世代は段階的リハビリが必要」という前提を内包しており、 当事者の自己認識（構造的排除の被害者）と根本的にずれている。 加えて、生活基盤が安定していない状態では「居場所」を受け取る余力がない。

柱３：高齢期への備えという方向性は評価される。しかし今の生活が切迫している当事者にとって、 65歳以降の話は「遠すぎる未来」だ。住宅・年金・生活保護という生活基盤の今すぐの強化が求められている。
