30年後の請求書が届いた
Q16〜Q19・総括と提言

Q16（欠けている視点）・Q17（生活と将来への不安）・Q18・Q19（政治参加）—— 4つの設問から届いた声を総括し、政策提言を届ける最終回だ。 老後・孤独・絶望・怒り・賠償要求。そして「社会的な困難としての認定」を求める83.3%の声。

この30年、ほとんど非正規でしか働くことができない状況のなか必死に働き続けてきたが、老後のための十分な資産形成がままならないまま気が付いたら50歳を超えてしまいました。

1971年生まれ / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）

「必死に働き続けた」のに「気が付いたら」——この言葉が連載全体を貫くテーマを凝縮している。 30年間の努力が報われず、気づいたときには手遅れだった。 請求書は、この世代ではなく、放置し続けた社会に届いている。

01Q16：プログラムに「欠けている」もの——83.3%が「社会的な困難としての認定」を求めた

「今回のプログラムで最も欠けていると感じる視点・支援」（Q16・複数選択）では、 すべての施策への要望を超えた答えが返ってきた。

Q16 プログラムに欠けていると感じる視点（複数選択 n=221）
居酒屋氷河期世代コミュニティ アンケート 2026年4月実施

最多は「就職氷河期を『社会的災害』として認定し責任を明確化すること」（184件、83.3%）。 個別施策への要望を差し置いて、10人中8人がこれを選んだ。

これはリスキリングでも居場所でもなく、 「この世代が経験してきた困難を社会全体として受け止めてほしい」を求めている。 施策の前に、この世代が経験した苦難を社会が認めることが必要だ——という声だ。

支援じゃねえ、補償だ！！現金でな！！！
1978年 / 女性 / 正規雇用（正社員・公務員等）
「支援」ではなく「補償」——この言葉の違いは大きい。支援は恩恵として与えられるものだが、補償は権利として求めるものだ。83.3%の「社会的な困難としての認定」要求は、この差異を正確に指している。
ANALYSIS

2位「年金・退職金格差への補償」（75.6%）、4位「緊急現金・現物給付」（50.2%）と合わせると、当事者が求めているのは「プログラム的介入（リスキリング・居場所）」ではなく「直接的な経済補償」だということが明確だ。現行プログラムの3本柱はいずれもプログラム的介入であり、補償の概念を含んでいない。ここに評価（平均1.68点）と要求（83.3%）の根本的なずれがある。

Q17は設問設計の制約がない自由記述だ。当事者が「今言いたいこと」を率直に書いた。 最多は「S. その他（49件、28.0%）」で、さらに8つのサブカテゴリに分類される。 2位に「老後・年金・貯蓄の不安（37件、21.1%）」が続く。 「絶望・安楽死・生きることへの言及」は4位（16件、9.1%）—— 設問の自由度が高いだけに、他の設問では届かなかった声が集まった。

032位：37件が語る「老後の絵が描けない」

23.4%が老後・年金・貯蓄への不安を書いた。しかしその内容は、 単なる「将来が心配」ではない——「30年働いたのに、老後の設計ができない」という怒りだ。

現在50代で何とか非正規の仕事はしているものの、年金受給年齢まで生活を支え、住宅を確保出来るほどの蓄えが出来るとは思えない。派遣の3年ルールは罰則がなく3年で直接雇用にならない人が多いのではないかと感じる。
1975年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
「年金受給年齢まで生活を支えられるか」——これは老後への不安ではなく、現在の問題だ。年金まで辿り着けるかどうかが今の課題になっている。
氷河期世代の夫は長年正社員で踏ん張ってきたが、昇給は頭打ち。一方で人手不足の若手世代は初任給から底上げされ、賃金上昇率で完全に取り残されている。私は50代でやっと正規雇用になれたが、退職金もなく老後の不安しかない。
1972年 / 女性 / 正規雇用（正社員・公務員等）
「賃金上昇率で完全に取り残されている」——正規雇用に就いていても、この世代は賃上げの恩恵を受けられていない。「正規 vs 非正規」だけでは捉えられない格差がある。
今、貧困老人になりきる前に浮上するための施策を本気で考えて欲しい。公務員など、公が正当な給料で大量に正職員として雇用するなどし、派遣労働制度を廃止して使い捨てでない安定した雇用形態に移行して欲しい。
1975年 / 女性 / 非正規雇用（パート・アルバイト・契約社員・派遣）
「貧困老人になりきる前に」という言葉が重い。老後への不安ではなく、今すでにそこへの坂道を転げ落ちている感覚だ。

就職が決まらない。どんなにスキルがあって、どんなに経験があったとしても、年齢と地域的な制約とが重なればどんな就職支援も無意味だ。

ANALYSIS

「低賃金・生活苦」と「政治不信」がそれぞれ22件でまったく同数というのは象徴的だ。生活苦が政治不信を生み、政治不信が「どうせ変わらない」という無力感を強化する。この悪循環が、Q19の「送っても変わらないと思っている（47.5%）」という数字に表れている。

0517件の絶望——「死にたい」「安楽死を認めてほしい」

この声をどう読むか

Q17では「安楽死を認めてほしい」「死にたい」「生きている意味がわからない」という言葉が16件届いた（9.1%）。Q15の4件と合わせると、この連載全体で20件の「死」に関わる言葉が届いた。個人の問題ではなく、30年間の構造的放置が生んだ集団的絶望として受け止めなければならない。

不安と絶望しかありません。努力しても努力しても報われず、きっと生活保護も受けられずに安楽死を求める事しか考えられないです。

ANALYSIS

プログラム全体評価の平均1.68点と、政策関心度の平均4.02点を並べると構図が見える。この世代は無関心から低く評価しているのではない。深く関心を持ち、自分の生活を通じて検証した結果として、厳しい評価を下している。この「高関心・低評価」こそが、今回の調査の最も重要な発見の一つだ。

08政策提言——当事者の声から導かれた7つの要請

PROPOSAL 01
就職氷河期が生んだ困難を社会的な問題として位置づけ、丁寧に向き合うこと
根拠：Q16にて83.3%（184人中184件）が「社会的な困難として認定し責任を明確化すること」を最も重要な課題の一つとして挙げました
  • 1999年・2004年派遣法改正等が当事者に与えた構造的損害を政府が公式に認定すること
  • 謝罪・認定・補償のプロセスなき支援策は「やった感」として受け取られることを認識すること
PROPOSAL 02
今すぐ届く緊急経済支援の導入
根拠：Q16「緊急現金・現物給付」50.2%、「プッシュ型アウトリーチ」52.0%
  • 生活困窮状態にある当事者への緊急現金・現物給付の実施
  • 申請主義からの脱却：マイナンバーを活用したプッシュ型給付の制度化
  • 年収300万円未満層への所得税・住民税の特例減税措置
PROPOSAL 03
年金・老後所得保障の抜本的強化
根拠：Q14「低家賃住宅優先入居」72.4%、「生活保護簡素化」60.2%、「年金補填」46.6%
  • 非正規・低収入期間が長かった氷河期世代への年金受給額の特別加算制度の創設
  • 最低保障年金水準を生活保護基準以上に引き上げること
  • 生活保護申請の水際対策を法的に禁止し、オンライン申請・簡素化を進めること
  • 低家賃公営住宅への氷河期世代向け優先枠の創設（Q14最多72.4%）
PROPOSAL 04
採用時の年齢差別を禁止する法規制の整備
根拠：Q16「年齢差別禁止法規制」46.6%、Q10「年齢差別・採用の壁」37件
  • 採用選考における年齢を理由とした不採用を禁じる法整備（努力義務から罰則付き禁止へ）
  • 不採用理由の開示義務化による選考透明性の確保
  • 氷河期世代採用に取り組む企業への特別法人税減税・助成金制度の拡充
PROPOSAL 05
非正規・派遣での長期就労が生んだ格差への補償
根拠：Q16「年金・退職金格差への補償」75.6%（2位）
  • 1999年・2004年派遣法改正以降の非正規誘導世代への年金補填措置の創設
  • 当事者参加の検討会議を設置し、特別給付金制度の設計を行うこと
  • 非正規就労期間に応じた退職金相当の国による上乗せ給付の検討
PROPOSAL 06
メンタルヘルス支援と介護離職対策の拡充
根拠：Q16「メンタルヘルス支援」47.1%、「介護離職対策」43.0%
  • 氷河期世代に特化したメンタルヘルス支援拠点（オンライン含む）の設置・無料化
  • 就労継続と親の介護が重なる「ダブルケア」への先手の制度支援
  • 複雑性トラウマへの対応ができる専門相談窓口の拡充
PROPOSAL 07
施策期間の延長と当事者参加型の継続的モニタリング
根拠：「3年で終わる施策で65歳以降を語るな」という批判が多数
  • 氷河期世代が70歳を迎えるまでを視野に入れた中長期計画として位置づけること
  • KPIに「貧困率」「精神的健康指標」「孤立死件数」等を複合的に設定すること
  • 当事者参加型の政策評価・見直し会議を年次で実施すること
おわりに——221件の回答が届けた「30年後の請求書」

今回のアンケートに寄せられた221件の回答は、数字である以上に、一人ひとりの30年間の蓄積だ。

全体評価の平均1.68点という数字は、無関心から来ていない。 政策関心度4.02点という高い関心を持ちながら、 自分の生活を通じて検証した結果として「評価できない」という答えが返ってきた。

「安楽死を認めてほしい」「死にたい」——4回を通じて20件の「死」に関わる言葉が届いた。 これを個人の問題として処理することはできない。 30年間の構造的放置が積み重ねた末の言葉として、政策立案者は正面から受け止める必要がある。

私たちが求めているのはこの一点だ。 「支援を受ける立場ではなく、30年間社会を支えてきた世代として、 今度は社会から支えてもらう権利がある」——この認識を、施策の出発点に置いてほしい。
